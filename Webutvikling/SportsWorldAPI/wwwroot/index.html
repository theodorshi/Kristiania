Velkommen til SportsWorld API

Tilgjengelige endepunkter

Athlete

Interface for athlete objekt:

id: int,
name: string,
gender: string,
price: int,
image: string,
purchaseStatus: boolean

Få alle athleter: GET /api/athlete

Returnerer liste med alle athleter i databasen:

[
{
"id" : 1,
"name": "Lionel Messi",
"gender": "Mann",
"price": 100000,
"image": "messi.png",
"purchaseStatus": false
},
{
"id" : 2,
"name": "Cristiano Ronaldo",
"gender": "Mann",
"price": 90000,
"image": "ronaldo.png",
"purchaseStatus": false
},
{
"id": 3,
"name": "Erling Braut Haaland",
"gender": "Mann",
"price": 200000,
"image": "haaland.png",
"purchaseStatus": false
}
]

Hent athlet på id: GET /api/athlete/{id}

Returnerer objekt med athlet med gitt id:

{
"id" : 1,
"name": "Lionel Messi",
"gender": "Mann",
"price": 100000,
"image": "messi.png",
"purchaseStatus": false
}

Legg til athlete: POST /api/athlete

{
"id" : 9,
"name": "Martin Ødegaard",
"gender": "Mann",
"price": 200000,
"image": "ødegaard.jpg",
"purchaseStatus": false
}

Oppdater athlete: PUT /api/athlete

For å oppdatere må et nytt objekt sendes med og overskriver objektet med id

{
"id" : 9,
"name": "Martin Ødegaard",
"gender": "Mann",
"price": 300000,
"image": "ødegaard.jpg",
"purchaseStatus": true
}

Slett athlete: DELETE /api/athlete/id

For å slette et objekt fra databasen må et athlete-objekt sendes med

Finance

Interface for finance objekt:

id: int,
moneyLeft: string,
numberOfPurchaes: int,
moneySpent: int

Få finans data: GET /api/finance

Returnerer finans objektet

{
"id": 1,
"moneyLeft": 1000000,
"numberOfPurchaes": 2,
"moneySpent": 190000
}

Oppdater finans: PUT /api/finance

{
"id": 1,
"moneyLeft": 2000000,
"numberOfPurchaes": 2,
"moneySpent": 190000
}
